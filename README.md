# Music
A tool to help your agent compose well. 
Mostly supports classical pieces for now. Your agent should have access to the internet, CLI/Machine, and be a frontier model capable of Deep Research. 

Reccomended Prompt:
```
Please generate me a piece in the style of x. Read through the repository and do deep research for the style of x before generating output. Ensure you iterate and refine your piece with subagent critique with diverse prompts.
```

Avoid using:
- OpenAI GPT Web
- Anthropic Claude Web
- Google Gemini Web

Use:
- Claude Code
- OpenAI Codex
- Google Antigravity
- Or other on-device, IDE compatible coding harnesses.
